# Atoms Demo 使用说明

一份简要的说明文档,涵盖在线访问、本地运行、核心流程、大模型接入、数据导入导出、部署与常见问题。

🔗 **在线演示**:https://AnnLin2019.github.io/Atoms_demo/

## 1. 项目简介

Atoms Demo 是一个「下一代 AI Agent 平台」演示:通过**智能体驱动**把一句话想法变成可运行、可交互的 Web 应用,**全程无需用户编码**。

- 多智能体团队:Mike(领队)、Iris(研究员)、Emma(产品经理)、Bob(架构师)、Alex(工程师)、David(数据分析师)
- 双通道生成:**内置模板引擎**(离线可用)与**真实大模型现场生成**(需自备 API Key)
- 纯前端静态应用,数据存于浏览器 `localStorage`

## 2. 在线访问

直接打开即可使用,无需安装:

```
https://AnnLin2019.github.io/Atoms_demo/
```

> 该地址由 GitHub Actions 每次推送 `main` 时自动构建部署到 GitHub Pages。

## 3. 本地运行

```bash
npm install     # 安装依赖
npm run dev     # 开发服务器 http://localhost:5173
```

生产构建:`npm run build`(产物在 `dist/`),`npm run preview` 本地预览。

## 4. 核心使用流程

1. **初始化 / 注册 / 登录**:首页「开始使用」→ 注册(任意邮箱 + 6 位以上密码)→ 登录
2. **新建项目**:工作台「＋ 新建项目」,输入一句话想法(或点示例)
3. **构建**:观察 AI 团队按「研究 → 需求 → 架构 → 编码 → 增长 → 上线」推进
4. **查看产物**:右侧切换「预览 / 代码 / 发布」三个视图
5. **迭代**:底部对话框继续提需求(如「把主题改成绿色」)
6. **导出**:发布视图可「下载独立 HTML」离线保存

## 5. 接入真实大模型(可选)

1. 工作台「🤖 模型设置」→ 选择服务商预设(OpenAI / DeepSeek / Kimi / 智谱 GLM)或手动填写
2. 填入 Base URL、API Key、模型名 →「测试连接」→「保存」
3. 新建项目时勾选「大模型实时生成」,由大模型现场编写专属代码

说明:

- 采用 OpenAI 兼容协议(`POST /chat/completions`)
- API Key 仅存于浏览器本地,不会上传
- 未配置或调用失败时,自动回退到内置模板(不会中断)

| 服务商   | Base URL                               | 模型示例          |
| -------- | -------------------------------------- | ----------------- |
| OpenAI   | `https://api.openai.com/v1`            | `gpt-4o-mini`     |
| DeepSeek | `https://api.deepseek.com/v1`          | `deepseek-chat`   |
| Moonshot | `https://api.moonshot.cn/v1`           | `moonshot-v1-8k`  |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`     |
| 第三方聚合 | `https://api.siliconflow.cn/v1`      | `deepseek-v3` 等  |

## 6. 项目导入 / 导出

- **导出**:项目卡片右上角「📤」导出单项目;顶部「📤 导出全部」导出全部为一份 JSON
- **导入**:顶部「📥 导入」选择 `.json` 文件,自动还原为当前账户的新项目(重新分配 id,不覆盖原数据)
- 有 `preview` 的项目导入后为「已上线」,否则判定为「构建中」并补齐构建

## 7. 部署到线上

纯前端静态应用(`base: './'`),`dist/` 可部署到任意静态托管:

- **GitHub Pages**(本仓库已配置 `.github/workflows/deploy.yml`,在 Settings → Pages 中把 Source 设为 GitHub Actions)
- Vercel / Netlify / Cloudflare Pages 等,拖拽或连接仓库即可

生成的单个应用也可在「发布」视图下载为独立 HTML,单独托管。

## 8. 常见问题(FAQ)

| 现象 | 原因与解决 |
| --- | --- |
| 测试连接报 `402 Insufficient Balance` | 账户**余额不足**,前往服务商平台充值后重试 |
| 测试连接报 `401` | API Key 无效或无权限,检查是否复制完整 |
| 测试连接报 `404` | baseUrl 错误,确认以 `/v1` 结尾 |
| 报 `429` | 请求过频或额度用尽 |
| 新建项目没有走 AI | 检查是否勾选「大模型实时生成」及模型配置是否已启用 |
| AI 生成失败(`非 JSON`) | 已自动回退模板,活动流有一条 ⚠️ 提示;可重试或换模型 |
| 刷新后数据还在吗 | 账号/会话/项目存于 localStorage,刷新不丢失;更换浏览器/设备需用导入导出迁移 |

## 9. 技术栈与结构

- React 18 + TypeScript + Vite · HashRouter
- 零 UI 框架,手写设计系统(CSS 变量 + 深色主题)
- 关键文件:`src/lib/llm.ts`(模型客户端)、`src/lib/aiGenerate.ts`(结构化生成)、`src/lib/engine.ts`(构建引擎)、`src/lib/templates.ts`(模板库)、`src/lib/store.ts`(持久化与导入导出)
